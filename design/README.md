# Тёмная тема GUI — как это устроено

Переработка дизайна затрагивает только слой интерфейса
(`parser_2gis/gui/**`) — парсер, CLI и запись файлов не менялись.

## Файлы

| Файл | Назначение |
| --- | --- |
| `parser_2gis/gui/theme.py` | Единственный источник правды по цветам, шрифтам и глобальным опциям PySimpleGUI |
| `parser_2gis/gui/components.py` | Переиспользуемые блоки: карточка, кнопки (3 стиля), поля, чекбокс, лог |
| `parser_2gis/gui/app.py` | Главное окно |
| `parser_2gis/gui/urls_editor.py` | Редактор списка ссылок (с нумерацией строк) |
| `parser_2gis/gui/urls_generator.py` | Генератор ссылок по городам и рубрикам |
| `parser_2gis/gui/rubric_selector.py` | Дерево рубрик с поиском |
| `parser_2gis/gui/settings.py` | Настройки |
| `parser_2gis/gui/error_popup.py` | Модальное окно ошибки |
| `parser_2gis/data/images/logo_dark.png` | Логотип под тёмный фон (светлая надпись) |
| `parser_2gis/data/images/loading_dark.gif` | Индикатор работы в акцентном зелёном |

`design/preview.html` — статичный макет всех окон, повторяющий те же токены.
Его удобно открыть в браузере, чтобы согласовать вид, не запуская приложение.

## Токены

```python
BACKGROUND        = '#0F1512'  # фон окна
BACKGROUND_DEEP   = '#0A0F0D'  # поля ввода, лог, дерево
SURFACE           = '#151D19'  # карточки
BORDER            = '#243129'
TEXT              = '#E8F0EC'
TEXT_MUTED        = '#8CA69A'
ACCENT            = '#46D07F'  # 2GIS-зелёный, адаптированный под тёмный фон
DANGER            = '#E4675C'
WARNING           = '#E5A94A'
```

## Типографика

Шрифты подбираются автоматически: Inter → SF Pro Text → Segoe UI → Helvetica Neue →
DejaVu Sans (первый установленный). Для журнала — моноширинный
(JetBrains Mono → SF Mono → Consolas → DejaVu Sans Mono).
Роли шрифтов: `TITLE`, `SECTION`, `BODY`, `BUTTON`, `SMALL`, `LOG` — в `theme.py`.

## Что изменилось по сравнению с прежним видом

- Тёмная палитра вместо светлой темы `Green`; зелёный акцент остался брендовым цветом.
- Окна собраны из карточек с заголовками-надзаголовками вместо `sg.Frame`.
- Единая типографика и отступы; кнопки трёх стилей: основная, обычная, опасная.
- Статус работы парсера виден сразу: подпись в шапке журнала, индикатор и подсказка в подвале.
- Сохранены все функции: горячие клавиши, контекстное меню (теперь тёмное), фильтр рубрик,
  выбор городов, синхронизация формата файла и расширения.
